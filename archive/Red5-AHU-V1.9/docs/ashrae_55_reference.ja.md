# ASHRAE Standard 55 — リファレンス

> *人間の居住に関する温熱環境条件*
> ANSI/ASHRAE Standard 55（現行版: 55-2023）

---

## TL;DR

ASHRAE 55 は、**どのような室内条件が人を温熱的に快適にするか**を定義する
国際的なルールブックです。Red5 Studio で目にするデフォルト値の多く —
21–27 °C の快適温度範囲、40–60 % RH の「スイートスポット」バンド、そして
Givoni エンベロープのコーナーアンカー — は、この標準に由来します。

これらの数値を把握しておくことは、オペレータが *「なぜバンドがそこに設定されて
いるのか?」* と尋ねるときや、新しい建物タイプ（ジム、ラボ、倉庫）がデフォルトの
意図的なオーバーライドを必要とするときに役立ちます。

---

## 1. ASHRAE 55 が実際に規定するもの

この標準は、単に *「21–27 °C が快適だ」* と述べているわけでは**ありません**。
**6 つの変数**に基づいて快適エンベロープを計算する方法を与えます:

| 変数 | 記号 | Red5 Studio でのオフィスデフォルト |
|---|---|---|
| 空気温度               | T<sub>a</sub>  | 21–27 °C    （T·CLIP スライダー）      |
| 平均放射温度           | T<sub>r</sub>  | ≈ T<sub>a</sub> と仮定                 |
| 相対湿度               | RH             | 40–60 %     （RH バンドスライダー）    |
| 気流速度               | V              | ≤ 0.20 m/s  （静止空気の仮定）         |
| 代謝率                 | M (met)        | 1.0–1.3 met （着座オフィス作業）       |
| 着衣量                 | I<sub>cl</sub> (clo) | 夏 0.5 clo / 冬 1.0 clo          |

これらを **Fanger の PMV/PPD モデル**（Predicted Mean Vote / Percentage Person
Dissatisfied、予測平均温冷感申告 / 予測不満足者率）に入力すると、標準は湿り空気
線図空間上の多角形 — 「許容快適域」 — を返します。静止空気で季節に応じた着衣の
一般的なオフィスの場合、この域はおおよそ次のように収束します:

| 季節 | 作用温度範囲 | RH 範囲 |
|---|---|---|
| 夏（0.5 clo、軽装） | **23–27 °C** | 30–60 % |
| 冬（1.0 clo、セーター + スラックス） | **20–24 °C** | 30–60 % |
| **通年の重なり（両方が成立）** | **21–27 °C** | **40–60 %** |

この通年の重なりこそが、Red5 Studio が **RH バンドスライダー** と
**3D WX T·CLIP スライダー** のデフォルトとして使用しているものです。

## 2. 許容性カテゴリ

ASHRAE 55 / EN 16798 は **3 つの** 目標満足度レベルを定義します:

| カテゴリ | 満足率 | 一般的な用途 |
|---|---|---|
| **A** | 90 % | プレミアム空間 — 手術室、役員室、博物館 |
| **B** | 80 % | 一般的なオフィス、学校の教室、ホテルの客室  ← *Red5 デフォルト* |
| **C** | 65 % | バックオブハウスの廊下、軽工業 |

快適多角形が狭いほど、満足度の目標は高くなります。Red5 Studio の
21–27 °C / 40–60 % のデフォルトは **Category A**（最も厳格な、プレミアム
オフィス仕様）に沿っています。建物が Category B の場合、標準に違反することなく
スライダーで安全に 20–28 °C / 30–60 % まで広げられます。

## 3. Red5 Studio における ASHRAE 55 の在り処

### 3.1 温度: T·CLIP スライダー（サイドバー、「3D WX · T·CLIP」）

- **デフォルト** 21–27 °C — ASHRAE 55-2023 Category A の通年の重なり
- **保存先** `localStorage['red5_t_clip_range']`
- **使用元** 3D WX のマゼンタスラブジオメトリ（`_buildRhBandSlab`） — スラブは
  この T ウィンドウ内でのみ描画され、そこでは室内 RH 制御が物理的に実行可能です
- **その他の使用元** `FREE | T·CLIP` チップ — `T·CLIP` モードのとき、気象散布の
  バンド内マーカー（1.6×）は RH チェックに加えて `T ∈ [T_lo, T_hi]` によって
  ゲートされます

### 3.2 湿度: RH バンドスライダー（サイドバー、スイートスポット範囲）

- **デフォルト** 40–60 % RH — ASHRAE 55 §5.2.3「humidity limits（湿度限界）」に、
  粘膜の健康（RH < 30 %）およびカビ発生の閾値（RH > 60 %）に関する WHO の
  空気質ガイダンスを組み合わせたもの
- **保存先** `localStorage['red5_sweet_spot_range']`
- **駆動対象** マゼンタスラブの断面、バンド内マーカーのハイライト、
  および選択された RH ウィンドウを BACnet コントローラへ送るバンドクランプロジック

### 3.3 快適多角形: Givoni エンベロープ（シアンのワイヤフレーム）

Givoni エンベロープは、Givoni の 1969 年の *Building Climatic Design* の多角形で
あり、生気候学的な戦略領域を追加することで ASHRAE 55 を **拡張** します:

| 領域 | ASHRAE 55 の対応 | Givoni が追加するもの |
|---|---|---|
| 快適コア | あり — PMV/PPD 快適域 | — |
| ソフトトリムバンド (B) | 部分的 — RH 境界 | パッシブな加湿/除湿の推奨 |
| 暑湿 (C+) | 域外 | 能動的冷房戦略 |
| 寒乾 (C–) | 域外 | 能動的暖房戦略 |
| パッシブソーラー | 域外 | 「無料暖房」戦略 |
| 自然換気 | 域外 | 「無料冷房」戦略 |
| 蒸発冷却 | 域外 | 「乾燥気候での無料冷房」戦略 |

つまり **ダッシュボードの Givoni エンベロープは ASHRAE 55 + 実行可能な HVAC
戦略アドバイス** です — 快適性 + それを安価に達成する方法。

### 3.4 気流速度の仮定

Red5 Studio は現在 **V ≤ 0.20 m/s**（静止空気）を仮定しています — これは着座
在室に対する ASHRAE 55 のデフォルトです。これが重要なのは、気流速度の増加
（例: シーリングファン）が **0.1 m/s あたり約 1.5 °C だけ快適エンベロープを上方に
シフト** させるためです — 操作可能なシーリングファンを備えた建物は、当社の
デフォルト T·CLIP を大きく外れた 28–29 °C でも快適になり得ます。建物が気流速度の
増加を快適性戦略として使用している場合は、T·CLIP を手動で 21–29 °C まで
広げてください。

## 4. デフォルトを意図的にオーバーライドすべきとき

21–27 °C / 40–60 % のデフォルトは、**空調された空間における着座〜軽作業の
在室者** — オフィス、学校、住宅、ホテル — 向けに調整されています。
ASHRAE 55 は明示的に次を対象と**していません**:

| 空間タイプ | 推奨オーバーライド | 理由 |
|---|---|---|
| 体育館、ダンススタジオ | T·CLIP 16–22 °C, RH 30–60 % | M ≥ 3.0 met — 身体が急速に熱を発生 |
| 業務用厨房 | T·CLIP 18–24 °C, RH 30–55 % | M ≈ 2 met、近傍に顕熱源 |
| クリーンルーム（半導体） | T·CLIP 20–22 °C, RH 45–55 % | 快適性ではなくプロセス駆動 |
| 博物館 / アーカイブ | T·CLIP 19–22 °C, RH 45–55 % | 収蔵品の保存（コレクション固有） |
| データセンター | T·CLIP 18–27 °C, RH 20–80 % | ASHRAE TC 9.9 の *機器* エンベロープであり快適性ではない |
| 病院手術室 | T·CLIP 20–24 °C, RH 30–60 % | ASHRAE 170 — 手術シーケンス |
| 倉庫、風除室 | 該当なし | ASHRAE 55 は適用されない; 建築基準を使用 |
| シーリングファンのある建物（V > 0.2 m/s） | T·CLIP 21–29 °C, RH は変更なし | 気流速度増加による快適性シフト |

オーバーライドした後は、**スライダーの RESET ボタンをダブルクリックすると
ASHRAE 55 Cat A のデフォルトに戻ります**。

## 5. 適合に関する注記

クライアントの仕様が ASHRAE 55-2023 適合の文書化を要求する場合:

- ダッシュボードの **Givoni Engine** バッジと RH バンドスライダーの「applied」
  チップは、在室空間が在室時間の ≥ 95 % にわたって標準の多角形内に保たれている
  ことを合わせて証明します。この指標は *Comfort 3D* のカバレッジ統計
  （3D WX パネル — 右下の「Pts / In-band / Sweet-spot %」表示）から取得してください。
- PMV/PPD の文書化については、ASHRAE 55 § 5.3.4 が、完全な PMV/PPD レポートの
  代替として *作用温度* 快適法（Red5 が使用しているもの）を認めています。
  T-clip および RH バンドスライダーの設定と、*Comfort 3D* レイヤーからの
  12 か月カバレッジチャートを提出してください。
