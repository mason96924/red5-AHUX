# ASHRAE Standard 55 — 참조 문서

> *Thermal Environmental Conditions for Human Occupancy (인체 재실을 위한 열환경 조건)*
> ANSI/ASHRAE Standard 55 (최신판: 55-2023)

---

## TL;DR

ASHRAE 55는 **어떤 실내 조건이 사람에게 열적으로 쾌적한가**를 정의하는 국제
규범입니다. Red5 Studio에서 보게 되는 대부분의 기본값 — 21–27 °C 쾌적 온도
범위, 40–60 % RH "스위트 스팟" 밴드, Givoni 엔벨로프 코너 앵커 — 는 이
표준에서 비롯됩니다.

이 숫자들을 알아두면 운영자가 *"밴드가 왜 저기에 설정되어 있나요?"* 라고 물을 때,
또는 새로운 건물 유형(체육관, 실험실, 창고)이 기본값을 의도적으로 재정의해야 할
때 유용합니다.

---

## 1. ASHRAE 55가 실제로 규정하는 것

이 표준은 단순히 *"21–27 °C가 쾌적하다"* 라고 말하지 **않습니다**. **여섯 가지
변수**를 기반으로 쾌적 엔벨로프를 계산하는 방법을 제시합니다:

| 변수 | 기호 | Red5 Studio 사무실 기본값 |
|---|---|---|
| 공기 온도             | T<sub>a</sub>  | 21–27 °C    (T·CLIP 슬라이더)        |
| 평균 복사 온도        | T<sub>r</sub>  | T<sub>a</sub> ≈ 로 가정             |
| 상대습도              | RH             | 40–60 %     (RH 밴드 슬라이더)       |
| 기류 속도             | V              | ≤ 0.20 m/s  (정지 공기 가정)        |
| 대사율                | M (met)        | 1.0–1.3 met (좌식 사무 작업)         |
| 착의 단열             | I<sub>cl</sub> (clo) | 여름 0.5 clo / 겨울 1.0 clo    |

이 값들을 **Fanger의 PMV/PPD 모델**(Predicted Mean Vote / Percentage Person
Dissatisfied)에 대입하면, 표준은 습공기 공간상의 다각형 — 즉 "허용 쾌적 영역"
— 을 반환합니다. 정지 공기 상태의 전형적인 사무실을 계절별 착의로 상정하면,
이 영역은 대략 다음으로 수렴합니다:

| 계절 | 작용 온도 범위 | RH 범위 |
|---|---|---|
| 여름 (0.5 clo, 가벼운 착의) | **23–27 °C** | 30–60 % |
| 겨울 (1.0 clo, 스웨터 + 슬랙스) | **20–24 °C** | 30–60 % |
| **연중 중첩 구간 (둘 다 성립)** | **21–27 °C** | **40–60 %** |

이 연중 중첩 구간이 바로 Red5 Studio가 **RH 밴드 슬라이더**와 **3D WX T·CLIP
슬라이더**의 기본값으로 사용하는 값입니다.

## 2. 허용 등급 (Acceptability categories)

ASHRAE 55 / EN 16798은 **세 가지** 목표 만족 수준을 정의합니다:

| 등급 | 만족 % | 대표 용도 |
|---|---|---|
| **A** | 90 % | 프리미엄 공간 — 수술실, 임원실, 박물관 |
| **B** | 80 % | 일반 사무실, 학교 교실, 호텔 객실  ← *Red5 기본* |
| **C** | 65 % | 후방 지원 복도, 경공업 |

쾌적 다각형이 좁을수록 만족 목표는 높아집니다. Red5 Studio의 21–27 °C /
40–60 % 기본값은 **등급 A**(가장 엄격한 프리미엄 사무실 사양)를 추종합니다.
건물이 등급 B라면, 표준을 위반하지 않고 슬라이더로 20–28 °C / 30–60 %까지
안전하게 넓힐 수 있습니다.

## 3. Red5 Studio에서 ASHRAE 55가 자리 잡는 위치

### 3.1 온도: T·CLIP 슬라이더 (사이드바, "3D WX · T·CLIP")

- **기본값** 21–27 °C — ASHRAE 55-2023 등급 A 연중 중첩 구간
- **저장 위치** `localStorage['red5_t_clip_range']`
- **사용처** 3D WX 마젠타 슬래브 지오메트리(`_buildRhBandSlab`) — 슬래브는
  실내 RH 제어가 물리적으로 실행 가능한 이 T 창 내부에서만 렌더링됨
- **추가 사용처** `FREE | T·CLIP` 칩 — `T·CLIP` 모드일 때, 날씨 산점도의
  밴드 내 마커(1.6×)는 RH 검사에 더해 `T ∈ [T_lo, T_hi]` 조건으로 게이팅됨

### 3.2 습도: RH 밴드 슬라이더 (사이드바, 스위트 스팟 범위)

- **기본값** 40–60 % RH — ASHRAE 55 §5.2.3 "습도 한계"에 점막 건강
  (RH < 30 %)과 곰팡이 발생 임계값(RH > 60 %)에 관한 WHO의 공기질 지침을
  결합
- **저장 위치** `localStorage['red5_sweet_spot_range']`
- **구동 대상** 마젠타 슬래브 단면, 밴드 내 마커 하이라이트, 그리고 선택된
  RH 창을 BACnet 컨트롤러로 밀어 넣는 밴드-클램프 로직

### 3.3 쾌적 다각형: Givoni 엔벨로프 (시안 와이어프레임)

Givoni 엔벨로프는 Givoni의 1969년 *Building Climatic Design* 다각형으로,
생기후(bioclimatic) 전략 영역을 추가하여 ASHRAE 55를 **확장**합니다:

| 영역 | ASHRAE 55 등가물 | Givoni가 추가하는 것 |
|---|---|---|
| 쾌적 코어 | 예 — PMV/PPD 쾌적 영역 | — |
| 소프트-트림 밴드 (B) | 부분적 — RH 경계 | 패시브 가습/제습 권고 |
| 고온-다습 (C+) | 범위 밖 | 능동 냉방 전략 |
| 저온-건조 (C–) | 범위 밖 | 능동 난방 전략 |
| 패시브 솔라 | 범위 밖 | "무료 난방" 전략 |
| 자연 환기 | 범위 밖 | "무료 냉방" 전략 |
| 증발 냉각 | 범위 밖 | "건조 기후 무료 냉방" 전략 |

따라서 **대시보드의 Givoni 엔벨로프는 ASHRAE 55 + 실행 가능한 HVAC 전략
조언** — 즉 쾌적성과 그것을 저렴하게 달성하는 방법을 함께 담고 있습니다.

### 3.4 기류 속도 가정

Red5 Studio는 현재 **V ≤ 0.20 m/s**(정지 공기)를 가정합니다 — 좌식 재실에
대한 ASHRAE 55 기본값입니다. 이것이 중요한 이유는, 상승된 기류 속도(예: 실링
팬)가 **0.1 m/s당 쾌적 엔벨로프를 약 1.5 °C씩 위로 이동**시키기 때문입니다 —
가동 가능한 실링 팬이 있는 건물은 우리의 기본 T·CLIP를 훨씬 벗어난 28–29 °C
에서도 쾌적할 수 있습니다. 건물이 상승된 기류 속도를 쾌적 전략으로 사용한다면,
T·CLIP를 수동으로 21–29 °C까지 넓히세요.

## 4. 기본값을 의도적으로 재정의해야 할 때

21–27 °C / 40–60 % 기본값은 **공조된 공간의 좌식~경작업 재실자** — 사무실,
학교, 주거, 호텔 — 에 맞춰 튜닝되어 있습니다. ASHRAE 55는 다음을 명시적으로
다루지 **않습니다**:

| 공간 유형 | 권장 재정의 | 이유 |
|---|---|---|
| 체육관, 댄스 스튜디오 | T·CLIP 16–22 °C, RH 30–60 % | M ≥ 3.0 met — 신체가 열을 빠르게 생성 |
| 상업용 주방 | T·CLIP 18–24 °C, RH 30–55 % | M ≈ 2 met, 인근 현열 발생원 |
| 클린룸 (반도체) | T·CLIP 20–22 °C, RH 45–55 % | 공정 주도형이며 쾌적 주도형 아님 |
| 박물관 / 아카이브 | T·CLIP 19–22 °C, RH 45–55 % | 유물 보존 (컬렉션별 상이) |
| 데이터센터 | T·CLIP 18–27 °C, RH 20–80 % | ASHRAE TC 9.9 *장비* 엔벨로프이며 쾌적 아님 |
| 병원 수술실 | T·CLIP 20–24 °C, RH 30–60 % | ASHRAE 170 — 수술 시퀀스 |
| 창고, 방풍실 | 해당 없음 | ASHRAE 55 미적용; 건축 법규 사용 |
| 실링 팬 있는 건물 (V > 0.2 m/s) | T·CLIP 21–29 °C, RH 변경 없음 | 상승 기류 속도에 의한 쾌적 이동 |

재정의한 뒤에는 **슬라이더의 RESET 버튼을 더블클릭하여 ASHRAE 55 등급 A
기본값으로 되돌리세요**.

## 5. 컴플라이언스 참고

클라이언트 사양이 ASHRAE 55-2023 준수 문서를 요구하는 경우:

- 대시보드의 **Givoni Engine** 배지 + RH 밴드 슬라이더의 "applied" 칩은 함께,
  재실 공간이 재실 시간의 ≥ 95 % 동안 표준의 다각형 내부에 유지됨을
  증명합니다. 해당 지표는 *Comfort 3D* 커버리지 통계(3D WX 패널 — 우측 하단
  "Pts / In-band / Sweet-spot %" 판독값)에서 가져오세요.
- PMV/PPD 문서화의 경우, ASHRAE 55 § 5.3.4는 전체 PMV/PPD 리포트의 대안으로
  *작용 온도* 쾌적 방법(Red5가 사용하는 방식)을 허용합니다. T·CLIP & RH 밴드
  슬라이더 설정값 + *Comfort 3D* 레이어의 12개월 커버리지 차트를 제출하세요.
