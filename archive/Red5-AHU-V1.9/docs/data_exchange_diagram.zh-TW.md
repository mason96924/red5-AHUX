## Data Flow Per Cycle (every 5 seconds)

```
STEP 1: READ
  collector.py -> dibt.Read("CSV_AHU01E.Present_Value")
  Returns: "16.9,83.8,45.0,1400,0,52.3,...,23.4,52.5,600,..."
           |--- AHU-01-E (34 pts) ---|--- VAV-01E-01 ---|--- VAV-01E-02 ---|

STEP 2: PARSE
  Using equipment_types.json point definitions:
    AHU points[0]  = OAT  = 16.9   (Outside Air Temp)
    AHU points[1]  = OAH  = 83.8   (Outside Air Humidity)
    AHU points[10] = SAT  = 15.0   (Supply Air Temp)
    AHU points[11] = SAH  = 90.8   (Supply Air Humidity)
    ...
    VAV points[0]  = t    = 23.4   (Zone Temp)
    VAV points[5]  = rh   = 52.5   (Zone RH)

STEP 3: CLASSIFY BAND
  classify_band(OAT=16.9, OAH=83.8)
  -> No exact match (16.9C falls in B3 temp range but 83.8% exceeds B3 RH)
  -> Nearest center: B7 (WARM-HUM) -- wait, actually at 16.9/83.8:
     B2 center = (10, 45), dist = 40.1
     B7 center = (29.5, 70), dist = 17.6
  -> Result depends on actual conditions

STEP 4: WRITE telemetry.json
  {
    "mock_mode": false,          <-- triggers LIVE badge
    "equipment": {
      "AHU-01-E": {
        "type": "ahu",
        "points": { "OAT": 16.9, "OAH": 83.8, "SAT": 15.0, ... },
        "active_band": {         <-- NEW: band classification
          "id": "B2",
          "sa_t_sp": 19.5,
          "oa_damper_sp": 15,
          "cc_mode": "OFF",
          "hc_mode": "MODERATE",
          "hum_mode": "COND_HUM"
        },
        "vavs": {
          "VAV-01E-01": { "points": { "t": 23.4, "rh": 52.5, ... } }
        }
      }
    }
  }

STEP 5: WRITE-BACK (Band Setpoints -> AHU)
  Build CSV write string (RW positions only):
    ",,,,,,,,,,,,,,,,,19.5,,15,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,*"
     |empty RO|  |SATSP| |OAD|  |--- empty RO positions ---|
  
  dibt.Write("CSV_AHU01E.Present_Value", csv_str)
  -> AHU controller picks up SATSP=19.5, OAD=15 at next scan
```

## Band Strategy (<!--FROZEN-->B1<!--/FROZEN-->-<!--FROZEN-->B10<!--/FROZEN-->)

```
                    OA Relative Humidity (%)
         0%    20%    40%    60%    80%    100%
    50C  |      B9    |             |  B10  |
    38C  |      B9    |       B8    |  B10  |
    35C  +------+-----+-------+----+-------+
    32C  |             |  B8   |    B10     |
    27C  +------+------+--B7---+----+-------+
    25C  |         B6          |
    22C  +------B4-----+--B5--+
    20C  |             |
    18C  +------+------+
    15C  |  B3  |  B2  |
     5C  +------+------+
   -50C  |  B1  |
         +------+

  Priority order for overlapping regions:
    B10 (extreme humid) checked before B8
    Fallback: nearest band center by Euclidean distance
```

## <!--FROZEN-->AHU<!--/FROZEN--> <!--FROZEN-->CSV<!--/FROZEN--> Object Structure

```
One CSV BACnet object per AHU, containing all points concatenated:

CSV_AHU01E.Present_Value = 
  "val1,val2,...,val34,val35,...,val44,val45,...,val54"
   |-- AHU-01-E ------|-- VAV-01E-01 --|-- VAV-01E-02 --|
   34 points (type 1)   10 pts (type 5)  10 pts (type 5)
   Total: 54 values

Point order defined by equipment_types.json:
  ahu_types.1.points[0..33] -> AHU labels
  vav_types.5.points[0..9]  -> VAV labels (repeated per VAV)

READ:  dibt.Read("CSV_AHU01E.Present_Value")  -> full CSV string
WRITE: dibt.Write("CSV_AHU01E.Present_Value", csv_with_RW_values)
       Only RW positions filled; RO positions empty
```
