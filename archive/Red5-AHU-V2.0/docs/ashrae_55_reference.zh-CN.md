# ASHRAE Standard 55 — 参考

> *人体热环境条件*
> ANSI/ASHRAE Standard 55（现行版本：55-2023）

---

## TL;DR

ASHRAE 55 是定义**何种室内条件能让人体获得热舒适**的国际规则手册。你在 Red5 Studio 中看到的大多数默认值——21–27 °C 的舒适温度范围、40–60 % RH 的"甜区"带，以及 Givoni 包络的角点锚——都来自该标准。

当操作员问*"为什么波段设在那里？"*，或当新的建筑类型（体育馆、实验室、仓库）需要刻意覆盖默认值时，了解这些数字就很有用。

---

## 1. ASHRAE 55 究竟规定了什么

该标准并**不**只是说*"21–27 °C 是舒适的"*。它给出了一种基于**六个变量**计算舒适包络的方法：

| 变量 | 符号 | Red5 Studio 中的办公室默认值 |
|---|---|---|
| 空气温度       | T<sub>a</sub>  | 21–27 °C    （T·CLIP 滑块）        |
| 平均辐射温度   | T<sub>r</sub>  | 假定 ≈ T<sub>a</sub>             |
| 相对湿度       | RH             | 40–60 %     （RH 波段滑块）       |
| 风速           | V              | ≤ 0.20 m/s  （静止空气假设） |
| 代谢率         | M (met)        | 1.0–1.3 met （坐姿办公）   |
| 服装热阻       | I<sub>cl</sub> (clo) | 0.5 clo 夏季 / 1.0 clo 冬季 |

将它们代入 **Fanger 的 PMV/PPD 模型**（预测平均投票 / 预测不满意百分比），该标准就会在焓湿空间中返回一个多边形——即"可接受舒适区"。对于处于静止空气、着季节性服装的典型办公室，该区域大致收窄为：

| 季节 | 操作温度范围 | RH 范围 |
|---|---|---|
| 夏季（0.5 clo，轻薄着装） | **23–27 °C** | 30–60 % |
| 冬季（1.0 clo，毛衣 + 长裤） | **20–24 °C** | 30–60 % |
| **全年重叠区（两者皆满足）** | **21–27 °C** | **40–60 %** |

这个全年重叠区正是 Red5 Studio 用作 **RH 波段滑块**和 **3D WX T·CLIP 滑块**默认值的依据。

---

## 2. 可接受性类别

ASHRAE 55 / EN 16798 定义了**三个**目标满意度等级：

| 类别 | 满意百分比 | 典型用途 |
|---|---|---|
| **A** | 90 % | 高端空间——手术室、高管办公室、博物馆 |
| **B** | 80 % | 典型办公室、学校教室、酒店客房  ← *Red5 默认* |
| **C** | 65 % | 后勤走廊、轻工业 |

舒适多边形越窄，满意度目标越高。Red5 Studio 的 21–27 °C / 40–60 % 默认值对应**类别 A**（最严格的高端办公室规格）。如果你的建筑属于类别 B，可以通过滑块安全地放宽至 20–28 °C / 30–60 %，而不违反该标准。

## 3. ASHRAE 55 在 Red5 Studio 中的落点

### 3.1 温度：T·CLIP 滑块（侧栏，"3D WX · T·CLIP"）

- **默认** 21–27 °C —— ASHRAE 55-2023 类别 A 全年重叠区
- **存储于** `localStorage['red5_t_clip_range']`
- **用于** 3D WX 品红色平板几何体（`_buildRhBandSlab`）—— 平板仅在此温度窗口内渲染，此处室内 RH 控制在物理上可执行
- **也用于** `FREE | T·CLIP` 标签 —— 处于 `T·CLIP` 模式时，天气散点的带内标记（1.6×）除 RH 检查外，还受 `T ∈ [T_lo, T_hi]` 门控

### 3.2 湿度：RH 波段滑块（侧栏，甜区范围）

- **默认** 40–60 % RH —— ASHRAE 55 §5.2.3 "湿度限值"，并结合 WHO 关于黏膜健康的空气质量指南（RH < 30 %）与霉菌生长阈值（RH > 60 %）
- **存储于** `localStorage['red5_sweet_spot_range']`
- **驱动** 品红色平板横截面、带内标记高亮，以及将所选 RH 窗口推送到 BACnet 控制器的波段钳制逻辑

### 3.3 舒适多边形：Givoni 包络（青色线框）

Givoni 包络是 Givoni 1969 年*《Building Climatic Design》*中的多边形，它通过增加生物气候策略区域**扩展**了 ASHRAE 55：

| 区域 | ASHRAE 55 对应 | Givoni 新增内容 |
|---|---|---|
| 舒适核心 | 是 —— PMV/PPD 舒适区 | — |
| 软修整带 (B) | 部分 —— RH 边界 | 被动加湿/除湿建议 |
| 炎热潮湿 (C+) | 界外 | 主动制冷策略 |
| 寒冷干燥 (C–) | 界外 | 主动加热策略 |
| 被动太阳能 | 界外 | "免费加热"策略 |
| 自然通风 | 界外 | "免费冷却"策略 |
| 蒸发冷却 | 界外 | "干燥气候免费冷却"策略 |

因此，**仪表盘中的 Givoni 包络就是 ASHRAE 55 + 可执行的 HVAC 策略建议**——既给出舒适条件，又给出如何低成本达成的方法。

### 3.4 风速假设

Red5 Studio 目前假设 **V ≤ 0.20 m/s**（静止空气）—— 这是 ASHRAE 55 针对久坐使用场景的默认值。这一点很重要，因为提高风速（例如吊扇）会**使舒适包络每 0.1 m/s 向上偏移约 1.5 °C**—— 装有可运行吊扇的建筑可以在 28–29 °C 下保持舒适，远超出我们默认的 T·CLIP。如果你的建筑将提高风速作为舒适策略，请手动将 T·CLIP 放宽至 21–29 °C。

---

## 4. 何时应刻意覆盖默认值

21–27 °C / 40–60 % 的默认值是针对**空调空间内久坐至轻度活动的使用者**调校的——办公室、学校、住宅、酒店。ASHRAE 55 明确**不**涵盖：

| 空间类型 | 建议覆盖值 | 原因 |
|---|---|---|
| 体育馆、舞蹈室 | T·CLIP 16–22 °C，RH 30–60 % | M ≥ 3.0 met —— 身体快速产热 |
| 商用厨房 | T·CLIP 18–24 °C，RH 30–55 % | M ≈ 2 met，附近有显热热源 |
| 洁净室（半导体） | T·CLIP 20–22 °C，RH 45–55 % | 由工艺驱动，而非舒适驱动 |
| 博物馆 / 档案馆 | T·CLIP 19–22 °C，RH 45–55 % | 文物保存（因藏品而异） |
| 数据中心 | T·CLIP 18–27 °C，RH 20–80 % | ASHRAE TC 9.9 *设备* 包络，而非舒适 |
| 医院手术室 | T·CLIP 20–24 °C，RH 30–60 % | ASHRAE 170 —— 手术流程 |
| 仓库、门厅 | 不适用 | ASHRAE 55 不适用；使用建筑规范 |
| 带吊扇的建筑（V > 0.2 m/s） | T·CLIP 21–29 °C，RH 不变 | 高风速舒适偏移 |

当你进行覆盖后，**双击滑块的 RESET 按钮即可恢复到 ASHRAE 55 Cat A 默认值**。

## 5. 合规说明

如果客户的规格要求提供 ASHRAE 55-2023 合规文档：

- 仪表盘的 **Givoni Engine** 徽章 + RH 波段滑块的"applied"标签共同证明使用空间在 ≥ 95 % 的使用时段内保持在标准的多边形之内。可从 *Comfort 3D* 覆盖率统计中获取该指标（3D WX 面板——右下角"Pts / In-band / Sweet-spot %"读数）。
- 对于 PMV/PPD 文档，ASHRAE 55 § 5.3.4 允许以*操作温度*舒适方法（即 Red5 所用方法）替代完整的 PMV/PPD 报告。只需提交 T-clip 与 RH 波段滑块设置 + 来自 *Comfort 3D* 图层的 12 个月覆盖率图表即可。
