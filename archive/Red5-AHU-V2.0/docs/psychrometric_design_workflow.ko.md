# 습공기선도: 기계설비 선정 설계자가 사용하는 방법

> **목적**: MEP 설계자들이 ~80년간 사용해 온 정적인 손으로 그린 습공기선도와
> Red5 Studio에 구현된 실시간 기후 인식 진단 엔진 사이의 격차를 메웁니다.
> 이 문서를 사용해 기계 엔지니어에게 Red5의 가치 제안을 설명하고
> 향후 "Designer Mode" 기능을 안내하세요.
>
> **대상 독자**: 기계 엔지니어, 영업 엔지니어, 제어 통합사, 건물 소유주 기술 대표.

---

## 고전적인 설계 워크플로

### 1단계 — 4개의 앵커 상태 플로팅

설계자는 모든 공조 결정의 경계가 되는 4개 점을 선도에 위치시킵니다:

| 점        | 의미                                  | 일반적 겨울/여름                          |
|-----------|---------------------------------------|-------------------------------------------|
| **OA**    | 외기 설계 공기 (ASHRAE 1%/99% bin)    | 예: 35 °C, 50% RH 여름 · −5 °C, 80% RH 겨울 |
| **RA**    | 존에서 돌아오는 환기                  | 24 °C, 50% RH (재실 설정점)               |
| **MA**    | OA + RA 혼합 후의 혼합 공기           | OA—RA 선 위에 위치, 비율 = 외기 분율       |
| **SA**    | AHU를 떠나는 급기                     | 일반적으로 13–14 °C 냉방 / 32–35 °C 난방   |
| **ZA**    | 존 공기 (재실자가 느끼는 공기)        | SA—부하 선 위에 위치                       |

이 5개 점이 선도 위에 공기 루프를 다각형으로 그립니다. Red5 대시보드는 이미
**Givoni 오버레이 + 동역학 애니메이션**으로 이를 애니메이션화합니다 — 바로 그 다이어그램입니다.

---

## 각 선분에서 무엇이 사이징되는가

### 1. 냉각 코일 사이징 (OA→MA→SA, 여름)

MA에서 SA까지의 수직 강하(현열 냉방) AND 습도비 W의 좌측 강하(잠열 / 제습)는
코일의 **총 엔탈피 차 Δh**를 정의합니다.

```
코일 톤수 = (CFM × 4.5 × Δh in Btu/lb) / 12,000
```

선도에서 바로 읽을 수 있는 두 가지 코일 선택 숫자:

- **장치 노점 (ADP)** — MA→SA 선을 포화 곡선까지 연장합니다. 그 교차점이 코일의
  유효 표면 온도입니다.
- **코일 바이패스 계수 (BF)** — `(SA − ADP) / (MA − ADP)`. 4-row 코일은 ~0.15, 8-row은
  ~0.05를 줍니다. 설계자는 row 깊이 + fin 간격을 선택해 요구되는 BF에 맞춥니다.

### 2. 가열 코일 사이징 (겨울, MA→SA 상향)

순수 수평 이동 (현열만).

```
코일 MBH = CFM × 1.08 × ΔT
```

### 3. 가습기 사이징 (겨울, MA→SA 우상향)

```
증기/팬식 용량 (lb/hr) = CFM × 4.5 × ΔW
```

여기서 ΔW는 선도 위 MA에서 SA로의 습도비 상승.

### 4. VAV 단말 박스 재열 (존 레벨, SA→ZA)

SA (13 °C, 8 g/kg)에서 ZA (24 °C, 컴포트존)로 가는 선은 **실내 현열 부하 기울기**입니다.
각 VAV 박스의 재열 코일은 각 존이 요구하는 ZA에 도달하도록 SA를 끌어올리는 크기로
선정됩니다.

### 5. 에너지 회수 휠(ERV/HRV) 선정

회수 전 두 점(OA, RA), 회수 후 두 점(OA′, RA′). **엔탈피 효율**:

```
ε = (h_OA − h_OA′) / (h_OA − h_RA)
```

가 휠의 선정 기준입니다. 설계자는 회수된 상태를 플로팅하고 더 작아진 Δh로 코일
사이징을 다시 돌립니다 — 일반적으로 코일 톤수가 30–50% 줄어듭니다.

### 6. 이코노마이저 전환 설정점

선도에서 OA 엔탈피 선(constant h)이 RA 엔탈피 선과 만나는 곳이 **그대로** 이코노마이저
컷오프입니다. 그 아래에서는 무료 냉방이 기계식보다 싸고, 위에서는 환기 재순환이 이깁니다.
Red5의 B1–B10 전략 곡선이 정확히 이 로직을 구현합니다.

### 7. 제습기 / 랩어라운드 코일 (실험실, 병원, 박물관)

종종 SA 설정점 아래로 과냉시켜 잠열 부하를 잡고, 다시 SA까지 현열 재열해야 합니다.
선도가 삼각형을 보여줍니다: MA → 과냉 점 → SA. 과냉 코일과 랩어라운드 재열 코일
모두 그 삼각형 변에서 사이징됩니다.

## Red5가 이 워크플로에 깔끔히 매핑되는 이유

설계자가 종이에서 정적으로 하는 일을, Red5 엔진은 **실시간 BACnet 텔레메트리로
동적으로** 수행합니다:

| 손으로 그린 선도 워크플로            | Red5 등가물                                                         |
|--------------------------------------|---------------------------------------------------------------------|
| ASHRAE bin 표에서 OA 플롯            | `collector.py` / Open-Meteo의 실시간 `OA_T`, `OA_RH`                |
| 코일 스케줄에서 SA 플롯              | 센서에서 실시간 `SAT`, `SAH`                                        |
| 손으로 OA→SA 프로세스 라인 그리기    | `OA→SA Projection` 오버레이 (옵션 A)                                |
| 라인 길이로 코일 Δh 추정             | Δ-h-vs-시간 뒷벽 차트 (3D 뷰)                                       |
| ZA가 컴포트존에 있는지 확인          | VAV CZ 산점도 (우측 벽) + 다크/라이트 에메랄드 상태 링              |
| 계산기로 제어 전략 비교              | 월별 × 사이트 4-전략 차트 + "% of Opt-SA captured"                  |

킬러 기능은 **40–60% RH "스위트 스팟" 스트립** + Givoni 오버레이입니다. 그것은 설계자가
보통 Carrier나 ASHRAE Fundamentals 선도 위에 색연필로 그리는 건물 물리 오버레이입니다 —
하지만 Red5의 것은 사용자의 범위 슬라이더에 자동으로 시프트하고 각 VAV의 상태를
실시간으로 등급화합니다:

- **다크 에메랄드** — 스위트 스팟 내부
- **라이트 에메랄드** — 컴포트존 내부 (Givoni)
- **오렌지** — 더운 쪽
- **다크 블루** — 추운 쪽

## 설계자가 실제로 Red5를 사용하는 방법

### 1. 계획설계 단계

사이트 위경도에서 1년 전체 3D Weather Strip을 실행하고, 2D X-Y Detail로 전환해
OA 클라우드를 살펴봅니다:

- **점이 컴포트존 왼쪽에 모임** → 기후가 난방 중심 → 큰 가열 코일이 있는 MAU 선정.
- **점이 우측 상단에 쌓임** → 냉방/잠열 중심 → 높은 ADP에 맞춰 냉각 코일 사이징, DOAS + 복사난방 고려.

### 2. 장비 선정

3가지 OA 밴드 프로젝션 모드를 토글:

- **Lines** → 각 밴드의 SA 타겟이 어디로 떨어지는지 확인.
- **Landing Zones** → 클러스터 중심이 코일이 도달해야 하는 최악의 SA 조건을 보여줌.
- **VAV Zone Delivery** → SA + 재열이 CZ 준수를 깨지 않고 각 존의 ZA를 전달할 수 있는지 확인.

### 3. 제어 전략 비교

4개 전략 모두 켠 월별 × 사이트. **B1-B10 + Dyn-Reset** 곡선 vs Fixed-SA가 연간 kJ/kg 절감을
줍니다 — 그것이 기계 엔지니어가 소유주에게 가져가는 달러 숫자입니다.

### 4. 시운전 / 사용 후

우측 벽의 실시간 VAV 산점도가 쿨링 타워 / DDC 튜닝 도구입니다:

- 너무 많은 점이 여름 오후 **오렌지(더움) 밴드**에 떨어지면 → SA 리셋 스케줄이 너무 공격적.
- 간절기에 **블루 점이 지배**한다면 → 난방 리셋이 부족하게 튜닝됨.

## 요약

기계 설계자는 습공기선도를 **3-in-1 도구**로 사용합니다:

1. **사이징 계산기** — 코일 톤수, MBH, 가습기 lb/hr, ERV ε, ADP, BF 모두 선도 기하학에서 읽음.
2. **제어 전략 비교기** — 이코노마이저 컷오프, SA 리셋 엔벨로프, 제습-재열 삼각형.
3. **시운전 검증기** — 전달된 ZA가 실제로 컴포트존에 떨어지는지 확인.

**Red5는 각각의 정적인 워크플로를 라이브 기후 인식 루프로 전환**하고, 설계자가 학교에서
배운 동일한 다이어그램 어휘를 사용하면서도 이제는 실제 BACnet 센서 데이터와 1년 전체의
역사적 기후로 구동됩니다.

## 향후 기능 훅: "Designer Mode"

**상태: V1.9 출시됨 (2026-02-09)** — 토글 버튼이 `dashboard.html → 3D Psychrometric Chart → X-Y Detail → + Designer Mode`에서 라이브.

기존 2D 선도 위에 4가지 사이징 숫자(코일 Δh, BF, ADP, ERV ε)를 오버레이하여 MEP 엔지니어가
대시보드를 떠나지 않고도 화면에서 바로 읽을 수 있게 하는 제안된 뷰. *"실시간 텔레메트리
시각화"* → *"설계 단계 의사 결정 지원"*의 루프를 닫을 것입니다.

구현 스케치:

- 2D X-Y Detail 오버레이의 토글 버튼: **`+ Designer Mode`**.
- 켜지면 MA→SA 프로세스 선을 단색 앰버로 그리고, 포화 곡선까지 연장해 **ADP**를 라벨 점으로 표시.
- `BF = (SA − ADP) / (MA − ADP)`를 계산해 선도의 우측 하단에 표시.
- 사용자 입력 CFM (사이드바 필드, 기본 10,000 CFM)을 가정해 세그먼트 끝점에서 Δh와 톤수 계산.
- 옵셔널 두 번째 토글 `+ ERV`로 회수 전/후 상태와 실시간 ε 표시.

### 출시된 V1 구현 세부사항

- **토글**: 앰버 `+ Designer Mode` 버튼 2D 오버레이 좌측 상단 (`px 280, top 46`).
- **입력 패널**: 8개 입력(CFM, OAfrac, OA T/RH, RA T/RH, SA T/RH)이 있는 떠다니는 앰버 테두리 카드. 상태는 `localStorage`의 `red5DesignerState`에 저장.
- **다각형**: 점선 슬레이트 OA→RA 혼합 선; 단색 2.6-px 앰버 MA→SA 프로세스 선; 점선 앰버 SA→ADP 포화 곡선 연장.
- **점**: 인라인 라벨이 있는 색 코딩된 점 (OA 핑크 `#fb7185`, RA 라임 `#a3e635`, MA 앰버 `#fbbf24`, SA 시안 `#22d3ee`, ADP 라이트 블루 `#67e8f9`).
- **판독 카드**: 선도 좌측 하단, 5행: 코일 Δh (kJ/kg), 냉방 톤수 (RT), ADP (°C), 바이패스 BF (색 코딩: 녹색 <0.08, 노랑 <0.18, 빨강 ≥0.18), 실내 현열 (kBTU/h).
- **ADP 솔버**: MA→SA 방향을 SA에서 아래로 0.1 °C 단계로 걸으며 투영된 선이 100% RH 곡선을 가로지를 때까지 진행 (`getW(T, 100)`).
- **가시성**: 선도가 T-Time, W-Time, 월별 × 사이트 모드로 전환되면 버튼 + 패널 숨김 (psy-chart 전용 도구).
- **설계상 라이브 텔레메트리와 분리됨** — Designer Mode는 라이브 점 클라우드와 동역학 애니메이션을 보완하는 병렬 "어떤 코일이 필요한가?" 뷰.

| 판독값      | 값             | 검증 체크                                              |
|-------------|----------------|--------------------------------------------------------|
| 코일 Δh     | 19.0 kJ/kg     | 일반적인 여름 냉각 코일                                |
| 냉방 톤수   | 30.7 RT        | 잠열 기후 400 CFM/톤 → 25 RT, 30 RT가 OA=35°C/50%RH의 20% OA 혼합에 맞음 |
| ADP         | 11.9 °C        | 7-row 코일 영역                                        |
