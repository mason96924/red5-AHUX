# ERV 밴드 시프트 통찰: "시간 손실"의 의미

> **함께 보기**: 2D X-Y 오버레이의 B-시프트 스트립(`#p3-band-delta`)과
> PSYCH 탭 AHU 사이드바의 시안색 ERV ROI 배지.
> 전체 맥락은 `psychrometric_design_workflow.md`와 함께 읽으세요.

---

## 운영자를 위한 핵심 요약
밴드의 **음수 Δ는 손실이 아닙니다**. **탈출 경로**입니다.
ERV 휠이 어려운 밴드(B1-B4 추운 쪽, B7-B10 더운 쪽)에서
꺼내는 매 시간은, 칠러·보일러·제어 로직이 더 이상 싸우지 않아도 되는 시간입니다.

연중 시간은 사라지지 않습니다. 단지 **다시 태깅**될 뿐입니다.
한 밴드에서 빼고, 다른 밴드에 더하고, 총합은 8,760시간 그대로입니다.

---

## 10밴드 다이어리 비유 (소유주 설명용)

건물은 1년치 일기를 씁니다. 매시간 10개 날씨 스탬프 중 하나가 찍힙니다:

| 밴드 | 라벨     | 평이한 설명                   |
|------|----------|-------------------------------|
| B1   | COLD-DRY | 한겨울 동결                   |
| B2   | COLD-MOD | 쌀쌀하고 중간 습도            |
| B3   | COOL-DRY | 시원하고 건조                 |
| B4   | MILD     | 카디건 입을 정도              |
| B5   | COMFORT  | 봄날 — 완벽                   |
| B6   | EDGE-HI  | 따뜻하고 끈적이기 시작         |
| B7   | WARM-HUM | 덥고 끈적함                   |
| B8   | HOT-HUM  | 폭염 + 습함                   |
| B9   | HOT-DRY  | 사막 같은 더위                |
| B10  | EXT-HUM  | 극심한 습도                   |

휠이 없으면, 각 시간은 **실제 외기 T/RH** 스탬프로 찍힙니다.
ERV 휠 ON 상태에서는 HVAC가 공기를 만나기 *전에* 공기를 미리 처리하므로,
일기는 각 시간을 **휠 통과 후 상태(OA')** 스탬프로 찍습니다.

여름 35°C / 85% RH (B8)의 한 시간은 휠을 거치면 27°C / 65% RH가 됩니다 — 같은 시간이
이제 B6으로 스탬프됩니다. **B8은 그 시간을 잃었고, B6은 그 시간을 얻었습니다.**
연간 누적해서 보면, 히스토그램이 눈에 띄게 B5 ± 1로 수렴합니다.

## 라이브 서울(한양대 박병원, 2,920시간) 예시

```
                      OA 버킷    OA' 버킷      Δ
B1   COLD-DRY              49h           0h    -49h
B2   COLD-MOD             171h           0h   -171h
B3   COOL-DRY               6h           0h     -6h
B4   MILD                  32h          12h    -20h
B5   COMFORT  ✅            43h       1,206h  +1163h
B6   EDGE-HI                33h         138h   +105h
B7   WARM-HUM              140h           0h   -140h
B8   HOT-HUM                 0h           0h      0
B9   HOT-DRY                 4h           0h     -4h
B10  EXT-HUM                 0h           0h      0
                          ─────       ─────
total                     2,920 h     ~1,356 h-매핑 (나머지는 '?')
```

> 읽는 법: **휠이 7개의 별개 운전 영역(B1-B4, B6, B7, B9)을
> 대부분 B5 — 컴포트 밴드 — 로 압축합니다.**

## 운영자가 도출할 수 있는 4가지 실용적 결론

### 1. B1-B4 시간 손실 → **난방 플랜트 적정 용량화**
추운 시간은 더 이상 설계 부하 상태로 가열 코일에 도달하지 않습니다 — 휠이
배기 열을 회수해 코일에 닿기 전에 B5/B6로 부드럽게 만듭니다.
다음 자본 지출 주기에서 보일러/히트펌프를 더 작게 교체할 수 있습니다.

### 2. B7-B10 시간 손실 → **칠러 적정 용량화**
냉방 측 대칭 이야기. 피크 설계일이 더 이상 칠러에 피크일로 도달하지 않습니다 —
사전 냉각된 상태로 도달합니다. 더 작은 칠러 + 유틸리티에서 낮은 피크 수요 요금.

### 3. B5 시간 획득 → **제어 루프를 B5에 맞춰 튜닝**
휠 이전에는 제어기가 계속 전략을 전환했습니다 (B1에선 난방, B7에선 냉방,
B4에선 이코노마이저...). 휠 이후로는 **운전 시간의 94%가 B5**입니다. PI 게인,
댐퍼 스케줄, 재열 밸브 곡선 — 모두 B5에 맞춰 최적화하세요. 건물이 운영적으로
*그곳에서 살고 있습니다*.

### 4. 계절별 손실 분포가 휠의 역할을 알려줍니다
- **겨울 손실 (B1-B4)** = 휠이 **예열** 중 (배기 열 회수)
- **여름 손실 (B7-B10)** = 휠이 **예냉** 중 (배기 냉기 회수)
- **간절기 손실 (B4, B6)** = 실내외 Δ가 작아 손실이 작음

## UI 요소 매핑

| UI 요소                                                | 의미                                                          |
|--------------------------------------------------------|---------------------------------------------------------------|
| **B-시프트 스트립** (`#p3-band-delta`, X-Y 우측 상단)   | 밴드별 OA 시간(흐림) vs OA' 시간(진함) + 부호 Δ                |
| **시안 ERV ROI 배지** (PSYCH 탭 AHU 사이드바)           | 같은 물리식의 `$/년 절감 · 회수 년수` 요약                     |
| **3D OA→SA 드롭 클라우드** (3D WX 탭)                   | 시안 리본 = 휠 작업, 온도 스펙트럼 드롭 = 코일 작업             |
| **Band src: OA \| OA' 칩** (X-Y 오버레이 상단)          | B1-B10이 원시 OA를 버킷팅할지 휠 통과 후 OA'를 버킷팅할지 전환 |
| **`vs prior` / `vs 1y` / `vs 5y avg` 버튼** (B-시프트)  | 과거 밴드 분포를 보라색 점선 고스트 막대로 오버레이             |

## 운영자가 자주 혼동하는 점 → 답변

**Q: "B1이 −49시간이라고 표시되는데, 운전 시간 49시간을 잃은 건가요?"**
**A:** 아닙니다 — 그 49시간의 겨울 시간은 여전히 발생합니다. 단지 휠이 제어기가
보기 전에 그 시간을 B5로 예열해버리기 때문에 B1으로 스탬프되지 않을 뿐입니다.
총 운전 시간은 변함없습니다. **각 시간이 분류되는 밴드**만 바뀌었습니다. Δ는
휠이 기후 노출을 *재분배*하는 정도를 알려주는 것이지, 시간을 얼마나 잃었는지를
알려주는 것이 아닙니다.

**Q: "그럼 전략에서 B1을 신경 쓸 필요가 있나요?"**
**A:** 네. `Band src: OA` 모드에서는 제어기가 여전히 원시 외기를 센싱하고 **보수적인
B1 SA 타겟**(낮은 SA, 최대 재열)을 선택합니다. 휠은 단지 코일의 일을 쉽게 만들 뿐 —
같은 SA 타겟, 더 적은 작업. `Band src: OA'`로 전환하면 휠이 만든 가능성을 이용해
**덜 공격적인 B5 SA 타겟**을 선택하는 휠 인식 제어기를 볼 수 있습니다.
