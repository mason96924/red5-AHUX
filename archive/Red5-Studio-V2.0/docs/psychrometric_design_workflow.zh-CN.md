## 经典设计工作流

### 第 1 步 — 绘制 4 个锚点状态

设计师在图上定位 4 个点,这些点界定每一个空气处理决策:

| 点     | 含义                              | 典型冬/夏                                 |
|--------|----------------------------------|-------------------------------------------|
| **OA** | 室外设计空气 (ASHRAE 1%/99% bin)  | 例:35 °C, 50 % RH 夏 · −5 °C, 80 % RH 冬 |
| **RA** | 从区域返回的空气                  | 24 °C, 50 % RH (使用状态设定点)           |
| **MA** | OA + RA 混合后的混合空气          | 位于 OA—RA 线上,比例 = 外气比例           |
| **SA** | 离开 AHU 的送风                   | 通常冷却 13–14 °C / 加热 32–35 °C         |
| **ZA** | 区域空气(使用者所感受到)        | 位于 SA—负荷线上                          |

这 5 个点把空气环路画成图上的一个多边形。Red5 仪表板已经把这个图当作 **Givoni 叠加 + 动力学动画** 来播放 —— 就是那个图。

## 从每条曲线段中算出什么尺寸

### 1. 冷却盘管选型 (OA→MA→SA,夏季)

从 MA 到 SA 的垂直下降(显热冷却)以及含湿量 W 向左下降(潜热/除湿)定义了盘管的 **总焓差 Δh**。

```
盘管冷吨 = (CFM × 4.5 × Δh in Btu/lb) / 12,000
```

从图上能直接读出的两个盘管选型数字:

- **机器露点 (ADP)** —— 将 MA→SA 线延伸到饱和曲线。该交点是盘管的有效表面温度。
- **盘管旁通系数 (BF)** —— `(SA – ADP) / (MA – ADP)`。4 排盘管通常给出 ~0.15;8 排给出 ~0.05。设计师选择排深 + 翅片间距以达到所需的 BF。

### 2. 加热盘管选型 (冬季,MA→SA 上行)

纯水平移动(仅显热)。

```
盘管 MBH = CFM × 1.08 × ΔT
```

### 3. 加湿器选型 (冬季,MA→SA 右上)

```
蒸汽/盘式容量 (lb/hr) = CFM × 4.5 × ΔW
```

其中 ΔW 是图上从 MA 到 SA 的含湿量上升。

### 4. VAV 末端再热 (区域级,SA→ZA)

从 SA (13 °C, 8 g/kg) 上到 ZA (24 °C, 舒适区) 的线就是 **房间显热负荷斜率**。每个 VAV 箱中的再热盘管按各区域所需的 ZA 来选型,把 SA 提升上去。

### 5. 能量回收转轮 (ERV/HRV) 选型

回收前两点 (OA, RA),回收后两点 (OA′, RA′)。**焓效率**:

```
ε = (h_OA – h_OA′) / (h_OA – h_RA)
```

是转轮的选型准则。设计师绘制回收后的状态并以较小的 Δh 重新计算盘管选型 —— 通常将盘管冷吨削减 30–50 %。

### 6. 经济器切换设定点

图上 OA 等焓线与 RA 等焓线的交点 **就是** 经济器截止点。低于它,免费冷却比机械式便宜;高于它,回风再循环胜出。Red5 的 B1–B10 策略曲线正好实现了这个逻辑。

### 7. 除湿器 / 环绕式盘管 (实验室、医院、博物馆)

通常需要过冷到 SA 设定点以下以抓住潜热负荷,然后显热再热回到 SA。图上呈现一个三角形:MA → 过冷点 → SA。过冷盘管和环绕式再热盘管都从该三角形的边长选型。

## Red5 为何如此清晰地映射到这个工作流

设计师在纸上静态完成的,Red5 引擎用 **实时 BACnet 遥测动态地** 完成:

| 手绘图工作流                  | Red5 等价物                                                       |
|------------------------------|-------------------------------------------------------------------|
| 从 ASHRAE bin 表绘制 OA       | `collector.py` / Open-Meteo 的实时 `OA_T`, `OA_RH`                |
| 从盘管计划表绘制 SA           | 传感器的实时 `SAT`, `SAH`                                         |
| 手绘 OA→SA 过程线             | `OA→SA Projection` 叠加 (选项 A)                                  |
| 从线长估计盘管 Δh             | Δ-h-vs-时间 后壁图 (3D 视图)                                      |
| 验证 ZA 在舒适区              | VAV CZ 散点 (右壁) + 深/浅祖母绿状态环                            |
| 在计算器上比较控制策略        | 月度 × 站点 4 策略图 + "% of Opt-SA captured"                     |

杀手特性是 **40–60 % RH "甜区"条带** + Givoni 叠加。那是设计师通常用彩色铅笔在 Carrier 或 ASHRAE Fundamentals 图上画的建筑物理叠加 —— 但 Red5 的会随用户的范围滑块自动平移,并实时为每个 VAV 评级:

- **深祖母绿** —— 在甜区内
- **浅祖母绿** —— 在舒适区 (Givoni) 内
- **橙色** —— 偏热侧
- **深蓝** —— 偏冷侧

## 设计师实际上如何使用 Red5

### 1. 方案设计阶段

在场地经纬度运行 3D Weather Strip 一整年,切换到 2D X-Y Detail,观察 OA 云:

- **点聚集在舒适区左侧** → 气候以加热为主 → 规定带大加热盘管的 MAU。
- **点堆积在右上方** → 冷却/潜热为主 → 按高 ADP 选大冷却盘管,考虑 DOAS + 辐射。

### 2. 设备选型

切换 3 种 OA-band 投影模式:

- **Lines** → 查看每个带的 SA 目标落在哪里。
- **Landing Zones** → 簇质心展示盘管必须达到的最坏 SA 条件。
- **VAV Zone Delivery** → 确认 SA + 再热能在不破坏 CZ 合规的前提下交付每个区域的 ZA。

### 3. 控制策略比较

四种策略全开的月度 × 站点。**B1-B10 + Dyn-Reset** 曲线 vs Fixed-SA 给出年 kJ/kg 节约 —— 那就是机械工程师带给业主的美元数字。

### 4. 调试 / 入住后

右壁的实时 VAV 散点是冷却塔 / DDC 调试工具:

- 如果夏季午后过多点落在 **橙色(热)带** → SA 重置计划太激进。
- 如果在过渡季 **蓝点占主导** → 加热重置欠调。

## 总结

机械设计师将焓湿图当作 **三合一工具**:

1. **选型计算器** —— 盘管冷吨、MBH、加湿器 lb/hr、ERV ε、ADP、BF 全部从图几何读取。
2. **控制策略比较器** —— 经济器截止、SA 重置包络、除湿再热三角。
3. **调试验证器** —— 确认交付的 ZA 实际落入舒适区。

**Red5 把每一种静态工作流转换为实时的、气候感知的循环**,使用设计师在学校学过的相同图式词汇 —— 但现在由真实 BACnet 传感器数据和一整年的历史气候驱动。

## 未来功能钩子:"Designer Mode"

**状态:V1.9 已出货 (2026-02-09)** —— 切换按钮位于 `dashboard.html → 3D Psychrometric Chart → X-Y Detail → + Designer Mode`。

一个提议的视图,把四个选型数字(盘管 Δh、BF、ADP、ERV ε)直接叠加在现有的 2D 图上,让 MEP 工程师可以不离开仪表板就直接从屏幕上读出。这将闭合 *"实时遥测可视化"* → *"设计阶段决策支持"* 的循环。

实施草图:

- 2D X-Y Detail 叠加上的切换按钮:**`+ Designer Mode`**。
- 打开时,把 MA→SA 过程线画为实心琥珀色,延伸到饱和曲线以标注 **ADP** 标签点。
- 计算 `BF = (SA – ADP) / (MA – ADP)` 并显示在图右下角。
- 假设用户输入的 CFM(侧栏字段,默认 10,000 CFM)从段端计算 Δh 和冷吨。
- 可选的第二个切换 `+ ERV` 显示回收前/后状态和实时 ε。

### 已出货 V1 实施细节

- **切换**:2D 叠加左上的琥珀色 `+ Designer Mode` 按钮 (`px 280, top 46`)。
- **输入面板**:浮动琥珀边框卡片,带 8 个输入(CFM、OAfrac、OA T/RH、RA T/RH、SA T/RH)。状态保存在 `localStorage` 的 `red5DesignerState`。
- **多边形**:虚线石板 OA→RA 混合线;实心 2.6 px 琥珀 MA→SA 过程线;虚线琥珀 SA→ADP 延伸到饱和曲线。
- **点**:带内联标签的色彩编码 (OA 粉 `#fb7185`、RA 酸橙 `#a3e635`、MA 琥珀 `#fbbf24`、SA 青 `#22d3ee`、ADP 浅蓝 `#67e8f9`)。
- **读数卡**:图左下,5 行:盘管 Δh (kJ/kg)、冷却冷吨 (RT)、ADP (°C)、旁通 BF (色编:绿 <0.08、黄 <0.18、红 ≥0.18)、室内显热 (kBTU/h)。
- **ADP 求解器**:沿 MA→SA 方向从 SA 向下以 0.1 °C 步进,直到投影线穿过 100 % RH 曲线 (`getW(T, 100)`)。
- **可见性**:图切换到 T-Time、W-Time、月度 × 站点模式时,按钮 + 面板隐藏(它是 psy-chart 专用工具)。
- **设计上与实时遥测解耦** —— Designer Mode 是补充实时点云和动力学动画的平行"我需要哪种盘管?"视图。
