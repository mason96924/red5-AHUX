# B1–B10 波段控制指南

> 🤖 **翻译基线说明**: 本文为英文原本(`band_guide.md`)的机器翻译基线。
> 发布或交付外部顾问前，建议由 HVAC 领域专业译者审校。

用于 AHU 控制的 Givoni 风格气候波段策略。每个波段为给定的外气条件选取最适合的送风目标 + 新风风阀位置，替代固定 T/RH 设定点控制。温带气候典型年节能：相对传统 SA 设定点控制减少 **70–75 %**。

> 波段的真理之源：`js/psy-3d-engine.js` 的 `BANDS` 数组，并镜像到 `collector.py`。不可只改一处。

---

## 平实语言摘要 (六年级水平)

"傻"的 AHU 遵循单一规则，如 *"无论外面什么样，把送风保持在 13 °C / 50 % RH。"* 这就像每天既穿冬大衣又穿短裤。

B1-B10 策略是 **10 套衣服**，每种天气情绪一套：

1. 看看外面 (T, RH)。
2. 选择匹配的波段 (B1 冷干 … B10 热湿)。
3. 使用 *该* 波段的 SA 目标 + 风阀位置。

舒适度相同，电费大幅降低 — 因为我们不再与天气对抗，而是迎合一半。

## 各波段控制细节

每个波段：何时激活、AHU 提供什么、各部件做什么。

### 🧊 冷波段

#### B1 — 极寒干燥 *(OA: −50…5 °C, 0–100 % RH)*
- **SA:** 21.0 °C / 40 % RH | **OA 风阀:** 15 %
- 冷却盘管: **OFF**
- 加热盘管: **HIGH** — 全年最大负荷
- 加湿器: **ON** (蒸汽 / 蒸发)

原因：仅取法定最低新鲜空气；让暖湿回风循环。加热盘管担纲主力，加湿器补偿冬季干燥。

#### B2 — 凉爽干燥 *(OA: 5–16 °C, 0–100 % RH)*
- **SA:** 19.5 °C / 35 % RH | **OA 风阀:** 15 %
- 冷却: OFF — 加热: 低-中调节 — 加湿器: 轻

原因：与 B1 相同的最小新风逻辑，负荷更轻。

---

### 🌤️ 温和波段 (节能器甜蜜区)

#### B3 — 温和干燥 *(OA: 15–22 °C, 0–35 % RH)*
- **SA:** 19.0 °C / 45 % RH | **OA 风阀:** 30 %
- 冷却: OFF — 加热: 仅修整 — 加湿器: ON (干燥 OA)

原因：OA 已接近 SA — 盘管工作量极小；加湿器补偿低 OA 湿度。

#### B4 — 温和中等湿度 *(OA: 18–23 °C, 32–55 % RH)* ⭐
- **SA:** 20.0 °C / 40 % RH | **OA 风阀:** **100 %**
- 所有盘管: **OFF** — 加湿器: OFF
- RA 风阀: **关** | 排气风阀: **开**

原因：外气 ≈ 所需 SA。完全绕过盘管；建筑直接呼吸外气。冷机和锅炉都关闭 → 最大节能。

---

### 🌞 温暖舒适波段

#### B5 — 温暖中湿 *(OA: 22–26 °C, 40–70 % RH)*
- **SA:** 23.5 °C / 50 % RH | **OA 风阀:** **100 %**
- 冷却盘管: 仅轻度修整 — 加热: OFF — 加湿器: OFF

原因：仍在节能器范围 — 100 % OA 比循环式机械制冷便宜。盘管做最后小修整。

#### B6 — 较暖 *(OA: 25–28 °C, 45–70 % RH)*
- **SA:** 25.0 °C / 55 % RH | **OA 风阀:** 50 %
- 冷却盘管: 中度调节 — 加热: OFF — 加湿器: OFF

原因：OA 现在比 SA 暖。与较冷回风 50/50 混合以降低盘管负荷。

---

### ☀️ 炎热波段

#### B7 — 炎热潮湿 *(OA: 26–36 °C, 45–90 % RH)*
- **SA:** 12.0 °C / 95 % RH | **OA 风阀:** 15 %
- 冷却盘管: **HIGH** + 除湿 — 加热: OFF (或再热修整) — 加湿器: OFF

原因：取法定最低炎热潮湿 OA；盘管将空气拽过饱和曲线挤出水分。SA 出盘管时接近饱和。再热盘管可将显热温度提至舒适。

#### B8 — 炎热极湿 *(OA: 32–45 °C, 65–100 % RH)*
- **SA:** 13.0 °C / 95 % RH | **OA 风阀:** 15 %
- 冷却盘管: **MAX** — 加热: 可选再热 — 加湿器: OFF

原因：与 B7 相同策略，放大版。全年盘管负荷最重的波段。

#### B9 — 炎热干燥 *(OA: 25–50 °C, 0–50 % RH)*
- **SA:** 15.0 °C / 40 % RH | **OA 风阀:** 15 %
- 冷却盘管: 重 **仅显热** (干盘管) — 加热: OFF — 加湿器: OFF (间接蒸发预冷器可大幅降低负荷)

原因：热但干燥 → 不需要除湿。盘管仅去显热。干旱气候改造应加蒸发预冷。

#### B10 — 极端炎热潮湿 (季风) *(OA: 28–50 °C, 80–100 % RH)*
- **SA:** 11.0 °C / 95 % RH | **OA 风阀:** 15 %
- 冷却盘管: **绝对 MAX** — 加热: 很可能作为再热 — 加湿器: OFF

原因：最糟情况。盘管将空气降至 ~11 °C 挤水；再热将除湿后空气升回舒适温度而不再增湿。

## 🎛️ 部件占空比 (5 秒摘要)

| 部件                       | 最忙时                | 空闲时                            |
|----------------------------|----------------------|----------------------------------|
| 加热盘管                   | B1, B2               | B3–B10 (B7/B8/B10 仅作再热使用)    |
| 冷却盘管                   | B7, B8, B10          | B1–B4                            |
| 加湿器                     | B1, B2, B3           | 所有温暖波段                       |
| **OA 风阀 @ 100 %** ⭐    | **B4, B5**           | 所有其他                           |
| OA 风阀 @ 15 % (最低)      | B1, B2, B7, B8, B9, B10 | B3 (30 %), B6 (50 %)          |

## 🔍 为何优于固定设定点控制

传统固定设定点 AHU 全年以恒定 SA 目标运行冷却盘管 — 即便在二月。B1-B10 看外气能 **免费** 提供什么，只为缺失的部分花能量。

温带气候下 B3+B4+B5 节能器波段约占年度 25–30 %，期间盘管基本 OFF。

仪表盘的 2D T×Time 图把这一差距可视化：绿色 B1-B10 累计曲线在年末通常仅约紫色 Total 曲线的 ~25 % → 约 75 % 节能。
