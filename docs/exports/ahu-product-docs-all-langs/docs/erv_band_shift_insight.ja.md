# ERV バンドシフトの洞察: "時間を失う" の意味

> 🤖 **翻訳ベースライン注記**: 本日本語ドキュメントは英語原本(`erv_band_shift_insight.md`)の機械翻訳ベースラインです。公開前にHVAC専門家のレビューを推奨します。

> **コンパニオン**: 2D X-Y オーバーレイの B-シフトストリップ(`#p3-band-delta`)および PSYCH タブ AHU サイドバーのシアン ERV ROI バッジ。完全な文脈は `psychrometric_design_workflow.md` と併せて読んでください。

---

## オペレータ向け TL;DR

**バンド上の負の Δ は損失ではありません**。それは **脱出ルート** です。
ホイールが硬いバンド(B1-B4 寒側、B7-B10 暑側)から引き上げる毎時間は、チラー、ボイラー、制御ロジックが闘う必要のない時間です。

時間は年間から消えません — ただ **再タグ付け** されるだけです。あるバンドから引き、別のバンドに足す、合計は 8,760 のまま。

---

## 10 バンド日記のメタファー (オーナー説明用)

建物は 1 年分の日記をつけます。各時間は 10 種類の天気スタンプのいずれかを受け取ります:

| バンド | ラベル    | 平易な気候             |
|------|----------|------------------------|
| B1   | COLD-DRY | 冬の凍結               |
| B2   | COLD-MOD | 寒い、中湿度           |
| B3   | COOL-DRY | 涼しく乾燥             |
| B4   | MILD     | セーター日和           |
| B5   | COMFORT  | 春の日 — 完璧           |
| B6   | EDGE-HI  | 暖かい、ジメつき始め   |
| B7   | WARM-HUM | 暑く湿気               |
| B8   | HOT-HUM  | 熱波 + 湿気            |
| B9   | HOT-DRY  | 砂漠級の暑さ           |
| B10  | EXT-HUM  | 極端な湿気             |

ホイールなしでは、各時間は **生の外気 T/RH** でスタンプされます。ホイール ON では、空気は HVAC システムに出会う *前* に前処理されるので、日記は各時間を **ホイール後の状態 (OA')** でスタンプします。

35 °C / 85 % RH の夏の時間 (B8) は、ホイール後に 27 °C / 65 % RH になるかも — 同じ時間が今は B6 としてスタンプ。**B8 はその時間を失った。B6 が得た。** 年々、ヒストグラムは目に見えて B5 ± 1 に集約します。

## ライブ ソウル (한양대 박병원, 2,920 h) の例

```
                      OA bucket   OA' bucket    Δ
B1   COLD-DRY              49h           0h    -49h
B2   COLD-MOD             171h           0h   -171h
B3   COOL-DRY               6h           0h     -6h
B4   MILD                  32h          12h    -20h
B5   COMFORT  ✅            43h       1,206h  +1163h
B6   EDGE-HI                33h         138h   +105h
B7   WARM-HUM              140h           0h   -140h
B8   HOT-HUM                 0h           0h      0
B9   HOT-DRY                 4h           0h     -4h
B10  EXT-HUM                 0h           0h      0
                          ─────       ─────
total                     2,920 h     ~1,356 h-mapped
```

> 列の読み方: **ホイールは 7 つの異なる運転体制 (B1-B4、B6、B7、B9) を主に B5 — 快適バンドに崩壊させる。**

## オペレータが引き出せる 4 つの実用的結論

### 1. 失われた B1-B4 時間 → **暖房プラントを適正化**
寒い時間は設計負荷で暖房コイルに届かなくなる — ホイールが排気の暖かさを回収しコイルに届く前に B5/B6 に和らげる。次のキャペックスサイクルでボイラー / ヒートポンプ置換を小さくできる。

### 2. 失われた B7-B10 時間 → **チラーを適正化**
冷房側で対称的な話。設計ピーク日はピーク日としてチラーに届かない — 予冷されて到着。小さいチラー + ピーク需要料金低減。

### 3. 獲得した B5 時間 → **B5 用に制御ループを調整**
ホイール前は制御器が戦略を切替続けていた (B1 暖房、B7 冷房、B4 エコノマイザ…)。ホイール後、**運転時間の 94 % が B5**。PI ゲイン、ダンパースケジュール、再熱バルブカーブは全て B5 用に最適化すべき — それが建物が運用上 *住む* 場所。

### 4. 損失の季節分布がホイールの仕事を教える
- **冬の損失 (B1-B4)** = ホイールが **予熱**(排気暖かさを回収)。
- **夏の損失 (B7-B10)** = ホイールが **予冷**(排気の涼しさを回収)。
- **中間期の損失 (B4、B6)** は屋内屋外 Δ が小さいので小さい。

## オペレータの一般的混乱 → 回答

**Q: 「なぜ B1 が −49h と表示？49 時間運転を失った？」**
**A:** いいえ — その 49 冬時間は依然発生しています。ホイールが制御器が見る前に B5 に予加熱したのでもはや B1 にスタンプされないだけ。総運転時間は不変; 変わったのは **各時間がどのバンドに分類されるか** だけ。Δ は失った時間ではなくホイールが気候曝露をどれだけ *再ルーティング* するかを示します。

**Q: 「では戦略で B1 を気にする理由は?」**
**A:** `Band src: OA` モードでは制御器が依然生の外気を感知し **保守的な B1 SA 目標**(低 SA、最大再熱)を選ぶから。ホイールはコイルの仕事を楽にするだけ — 同じ SA 目標、より少ない仕事。`Band src: OA'` に切替えると **ホイール対応制御器** が **ホイールが可能にした控えめな B5 SA 目標** を選ぶ様子が見えます。
