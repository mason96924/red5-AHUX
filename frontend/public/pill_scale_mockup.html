How it works: Each pill stores its anchor as a % of the image stage (not raw pixels) and reads a CSS variable --img-scale via calc() for every dimension — font-size, padding, border, shadow. A ResizeObserver on the image element sets that variable to renderedWidth / referenceWidth on every resize. Total prod overhead: ~1 ResizeObserver per modal + 5 lines of CSS calc per pill.
