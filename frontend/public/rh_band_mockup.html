How this would be wired into the real 3D WX scene:
Geometry — two parametric ribbons in psychrometric T×W space, each tracing W = 0.622 · (RH · Psat(T)) / (Patm − RH · Psat(T)) along the X axis, then extruded along the Z (time) axis — using the existing BufferGeometry path that draws the Givoni envelope. Two-sided MeshBasicMaterial, alpha 0.18, additive blending, no depth-write so the slab does not clip the dots behind it.

Hit-test — on every FETCH WEATHER DATA response the existing weatherSamples[] array gets a derived rh column (already there). A 1-liner boolean inBand = (s.rh ≥ rhMin && s.rh ≤ rhMax) drives marker size + halo.

Reactivity — the slab geometry and hit-test bind to the same rhBandMin / rhBandMax state already used by the sidebar pills and the 2-D psychrometric chart, so dragging the sliders updates all three views in lock-step.

Cost — ~80 lines net add to the 3D WX component. No new dependencies. No impact on light/dark mode or the new DIM compensation (zone is rendered inside the existing red5-graphic-zone wrapper).
